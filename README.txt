FUCKIN CLOCK — standalone PWA
Extract ZIP. Create a public GitHub repository. Upload all extracted files to the repository root. In Settings > Pages select Deploy from a branch, main, / (root), Save. Open the published HTTPS URL in Safari, then Share > Add to Home Screen. Gear settings persist locally. No API or location permission required. Clock uses device time and browser time-zone data. Unnecessary Time reports wall-clock seconds since midnight, not elapsed physical seconds on daylight-saving transition days. No voice. Hub integration: use the published URL in the future Hub catalog.
